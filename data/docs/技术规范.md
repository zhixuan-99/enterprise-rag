# 云策科技 技术规范

## 一、API 接口规范

1. 接口风格采用 RESTful，资源用名词复数表示，如 /api/v1/users、/api/v1/orders。
2. 鉴权统一使用 JWT Token，在请求头 Authorization: Bearer <token> 中携带，Token 有效期 2 小时。
3. 统一响应格式为 {"code": 0, "message": "success", "data": {}}，code=0 表示成功。
4. 错误码规范：400 参数错误，401 未认证，403 无权限，404 资源不存在，500 服务器内部错误。
5. 所有接口必须限流，默认每用户每秒 10 次请求。

## 二、数据库规范

1. 数据库使用 PostgreSQL，版本不低于 14。
2. 表名使用小写下划线命名，如 user_profile、order_detail。
3. 所有表必须包含 id（自增主键）、created_at、updated_at 三个字段。
4. 高频查询字段必须建立索引，索引命名规则 idx_表名_字段名。
5. 禁止使用 SELECT *，必须显式列出需要的字段。

## 三、代码规范

1. 后端统一使用 Python，代码需通过 flake8 检查，行长不超过 120 字符。
2. 函数命名使用小写下划线，类名使用大驼峰。
3. 所有公开接口必须写 docstring 和单元测试，测试覆盖率不低于 80%。
4. Git 提交信息格式：<type>(<scope>): <subject>，type 取 feat/fix/docs/refactor 之一。

## 四、部署规范

1. 服务容器化部署，使用 Docker 和 Kubernetes。
2. 生产环境日志必须接入集中日志平台，保留 90 天。
3. 发布必须走灰度发布流程，先 10% 流量观察 30 分钟，无异常再全量。
